The HAL file(s) in this directory contain multiple genomic alignments generated by
progressive Cactus ( Armstrong et al. 2020 ; doi:10/ghmthr )
or Minigraph-Cactus ( Hickey et al. 2024 ; doi:10/gsfwq7 ).
They can be accessed using the HAL format API ( Hickey et al. 2013 ; doi:10/gb5g3b ).

HAL alignment files generated before August 2026 have been moved to a central location:
  https://ftp.ensembl.org/pub/misc/compara/multi/hal_files/

Many of these are named according to a loose naming convention
(e.g. 'Aves-59-way_20230814.hal'), including the species collection
(e.g. 'Aves'), species count (e.g. '59'), and datestamp (e.g. '20230814').

It is recommended to access these HAL files from the central location,
which also includes auxiliary metadata and checksum files. Given a
file named 'cactus.hal', auxiliary files may include:

cactus.hal.sha512sum
  Contains SHA512 checksum which may be used to verify the given HAL file.

cactus.alignment.tsv
  Contains alignment metadata in TSV format, with the following fields:
    hal_file_name : name of the HAL file
    hal_file_size : size of the HAL file in bytes
    date : indicative date of generation of the Cactus alignment, in ISO-8601 format
    source : source of the HAL file (e.g. 'Ensembl', 'HPRC', 'UCSC')
    hal_file_url : URL at which the HAL file can be accessed
    comments : free text column of additional information

cactus.assemblies.tsv
  Contains assembly metadata in TSV format, with the following fields:
    hal_genome : name of the genome assembly in the HAL file
    accession : accession associated with the assembly (e.g. 'GCA_000001405.29')
    comments : free text column of additional information
    subgenome : optional column indicating the subgenome of a polyploid genome assembly

cactus.nh
  Contains the Cactus alignment species tree in Newick format.
